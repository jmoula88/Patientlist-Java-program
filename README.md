# PatientList-Java

PatientList-Java is a Java application designed to read, manage, and update patient information stored in text files. The program demonstrates Java file handling, object-oriented programming, data validation, and processing records from external files.

## Features

- Reads patient information from text files
- Processes and updates patient records
- Handles patient data using Java classes and objects
- Works with multiple input files
- Demonstrates file input/output and exception handling
- Identifies and handles errors in patient data

## Technologies Used

- Java
- Eclipse IDE
- Java Development Kit (JDK)
- Text files for data storage

## Recommended Software

The project can be opened and run using **Eclipse IDE for Java Developers**.

Eclipse can be downloaded from the official Eclipse website.

You will also need a **Java Development Kit (JDK)** installed on your computer.

Other Java IDEs, such as IntelliJ IDEA or Visual Studio Code with the Java extensions installed, may also be used.

## Project Structure

```text
PatientList-Java/
├── src/
│   └── Patient.java
├── NewPatientList.txt
├── PatientErrorsW4.txt
├── PatientListW3.txt
├── PatientListW4.txt
└── RemovePatientList.txt
```

The `src` directory contains the Java source code. The text files contain patient information used by the application.

## How to Run in Eclipse

1. Install the Java Development Kit (JDK).
2. Install Eclipse IDE for Java Developers.
3. Download or clone this repository.
4. Open Eclipse.
5. Import the project into your Eclipse workspace.
6. Make sure the project's `src` folder is configured as the source folder.
7. Open `Patient.java`.
8. Run the program using **Run → Run As → Java Application**.

The program will process the patient information contained in the associated text files.

This project was created to practice Java programming concepts including:

- Object-oriented programming
- Reading and writing files
- Working with external data
- Data validation
- Exception handling
